# Healthcare Web Application – QA Portfolio Project

## Project Overview

This repository contains manual QA testing artifacts for a healthcare web application, **Manage My Patient Portal (MMP)**.

The application supports interactions between Patients, Doctors, and Administrators, including patient registration, appointment management, profile management, medical reports, messaging, payments, and role-based functionality.

The purpose of this project is to demonstrate practical experience in requirement analysis, test case design, test execution, defect reporting, SQL validation, and AI-assisted software testing.

## Defect Management Workflow

The defect management process followed during testing included:

1. Execute the test case.
2. Identify unexpected application behavior.
3. Reproduce and validate the defect.
4. Create a Jira bug.
5. Document expected and actual results.
6. Set appropriate priority/severity information.
7. Link the defect to the relevant test case where applicable.
8. Track the defect status.
9. Retest after a fix is provided.
10. Perform regression testing where required.
